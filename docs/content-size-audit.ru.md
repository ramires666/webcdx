# Аудит размеров данных: расширение 0.3.8, агент и Gate alpha.5

Проверены разбор ответа AI Studio, передача в расширении, хранение операции,
локальный HTTP, Native Messaging Studio, Bridge/MCP Gate, поток Gate → агент,
возврат результатов, операции с файлами, команды и браузерные загрузки.

Фиксированные пределы размера данных на этих путях удалены без замены большим числом.

| Место | Прежнее поведение | Исправление |
|---|---|---|
| Ответ модели | Отказ после 64 КиБ | Полный разбор JSON; содержимое строк сохраняется |
| Системные инструкции | Отказ после 64 КиБ | Порог удалён |
| Локальный запрос | Клиент и HTTP агента отказывали после 1 МиБ | Предел тела запроса удалён с обеих сторон |
| Локальный результат | Предел 4 МиБ, подмена результата ошибкой | Возвращается полный результат |
| Native Messaging Studio | Запрос 1 МиБ, ответ 4 МиБ, не более 64 частей | Суммарные программные пределы удалены; ответы передаются частями |
| Операции Gate | Запрос 64 КиБ, результат 2 МиБ | Полный запрос и результат в хранилище операции |
| Обычный MCP Gate | Запрос 1 МиБ | Порог удалён |
| Поток Gate → агент | Scanner отказывал на строке больше 2 МиБ | Чтение NDJSON без заданного предела строки |
| Ответ агента → Gate | Отказ после 2 МиБ | Порог удалён |
| Внешний браузерный MCP | Ответ 2 МиБ | Возвращается полный ответ |
| Файлы агента | Предел 10 МиБ при чтении, записи, правке и проверке хеша | Файл обрабатывается полностью, запись остаётся атомарной |
| `read_file` | Обрезка по общему бюджету ответа | Возвращается весь файл либо диапазон строк, явно выбранный клиентом |
| Поиск по файлам | Пропуск больших файлов, строка максимум 1 МиБ, текст совпадения 4096 байт | Поиск читает полные строки и возвращает полный текст совпадения |
| Каталоги и поиск | Встроенные максимумы количества результатов и бюджет ответа | Ограничение количества действует только по явно указанному параметру клиента |
| Ввод команды | Отказ для stdin больше 10 МиБ | Порог удалён |
| Вывод команды | По умолчанию сохранялись только первые 50 МиБ | По умолчанию журнал полный; явная настройка пользователя остаётся действующей |
| Чтение журнала команды | Запрошенный объём дополнительно ограничивался 1 МиБ и общим бюджетом | Клиент может запросить нужный объём; обычная порция по умолчанию сохраняется |
| Браузерные файлы | Отказ загрузки/отправки после 64 МиБ, отмена из-за общего бюджета артефактов | Пределы размера и отмена по размеру удалены |
| Операция в Chrome | Полное содержимое несколько раз попадало в состояние и ID ответа | ID содержит SHA-256; большая операция переносится в local-хранилище с unlimitedStorage |
| Обнаружение MCP-инструментов | 1000 инструментов / 20 страниц | Пороги удалены; повтор курсора по-прежнему считается ошибкой сервера |

Защита от перезаписи существующего файла без условия, проверка SHA-256, разрешённые
папки, выбор инструментов, согласие и сохранённые ключи операций действуют.
Снятие пределов размера не должно превращать повтор запроса в повторную запись.

Не смешиваются с содержимым файлов: ограничения HTTP-заголовков и форм входа,
формат идентификаторов, сроки выполнения команд, компактность консольного превью
и диагностических записей. Они не отбрасывают тело сохраняемого файла.
Размер доступной памяти, свободное место и ограничения самого Chrome/ОС остаются
свойствами платформы; новый программный предел размера файла не вводится.

Проверки включают большие UTF-8-файлы на реальных локальном и Gate-маршрутах,
полное чтение результата, повтор с прежним ключом после переподключения,
чтение/правку/поиск файла больше бывших 10 МиБ, браузерный файл больше 64 МиБ,
сохранение состояния после имитации квоты Chrome и восстановление `write_file`
из уже готового ответа без генерации нового кода.

Для установки: обновить расширение и сохранённую вкладку, заменить и перезапустить
агент alpha.5 прежним батником. Для прямого локального режима Gate не требуется;
для исправления его маршрута заменить и перезапустить Gate alpha.5 с прежней базой.
Агент скомпилирован: `bin/ai-studio-bridge/webcodex-agent.exe`. Самостоятельная сборка
при наличии готового комплекта не нужна. EXE, ZIP и локальные настройки в Git не входят.

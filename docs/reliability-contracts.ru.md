## Каталог

Расширение получает действующие схемы через `tools/list`. Локальный агент
публикует v5, поддерживаются также старые v3 и v4. Gate добавляет `agent_id`.
Расширение исключает `browser_*` и подставляет `agent_id`, `request_key`, `delivery`
самостоятельно. Пользователь выбирает разрешённый поднабор. Дополнительные
инструменты удалённого сервера обрабатываются по полученной схеме.

В таблице обязательные аргументы выделены жирным. Строки имеют тип string,
счётчики и смещения integer, флаги boolean. `argv` содержит массив строк,
`env` содержит объект строковых значений. Пути абсолютные на стороне агента.

| Инструмент v5 | Аргументы | Эффект и предусловие |
| --- | --- | --- |
| read_file | **path**, offset, limit, delivery | Чтение текста по строкам либо точного вложения, SHA всего файла |
| write_file | **path**, **content**, if_absent, expected_sha256 | Атомарная запись, ровно одно из условий отсутствия или SHA |
| list_directory | **path**, max_entries | Чтение одного каталога |
| search_files | **path**, **pattern**, glob, regex, max_results | Рекурсивное чтение, регулярное выражение по флагу |
| exec_command | **cwd**, **request_key**, command, argv, env, stdin, timeout_seconds, yield_time_ms | Запуск процесса, ровно command либо argv, устойчивый ключ запуска |
| poll_command | **session_id**, stdout_offset, stderr_offset, max_bytes | Чтение новых байтов и состояния процесса |
| cancel_command | **session_id** | Завершение процесса и дерева |
| edit_file | **path**, **expected_sha256**, **edits** | Упорядоченный массив объектов с обязательными old_text, new_text и необязательным replace_all, проверка SHA |
| find_files | **path**, name_glob, kind, max_results | Рекурсивное чтение имён |
| move_path | **source**, **destination**, expected_sha256 | Перемещение без перезаписи, SHA для обычного файла |
| delete_path | **path**, expected_sha256 | Удаление файла либо пустого каталога, SHA для файла |
| list_allowed_roots | Нет | Доступные корни и unrestricted |
| list_commands | limit, status | Чтение недавних процессов, limit от 1 до 500 |
| list_agents | Нет | Чтение доступных агентов, добавляется транспортом |

Точные ограничения и допустимые значения берутся из схем. v3 допускает запись
без SHA, команды только через command и общий offset. v4 вводит условия записи,
argv, env, stdin, раздельные потоки и файловые операции. v5 добавляет обязательный
request_key запуска и list_commands. Сырое тело v2 предназначено для content
write_file и command exec_command. Массивы и объекты требуют структурированного
участка. Пустые content, stdin и new_text допустимы согласно схеме.
[Схемы файлов](../cmd/agent/tool_schemas.go),
[схемы v5](../cmd/agent/command_schemas.go).

Любой инструмент, отправленный через operations/create, получает ключ всей
операции независимо от наличия request_key в его схеме. Защита запуска команды
дополнительно действует внутри агента. Одинаковый ключ с другими аргументами
вызывает конфликт. Полный каталог и сценарии команд проверяются Go-тестами.

## Сохранённое состояние

| Компонент | Текущий контракт | Решение для следующих этапов |
| --- | --- | --- |
| Расширение | webcodexState в storage.session, большие снимки в storage.local по указателю, явной версии схемы нет | Ввести версию и миграцию перед изменением структуры, проверить сбой между двумя записями |
| Разрешения | bridgeAuto и bridgeAuth в storage.local | Миграция сохраняет выбор и явное согласие |
| Агент | Файлы операций, создание через O_EXCL, Sync до эффекта, атомарный конечный результат | Сохранить формат ключей и обработку неизвестного исхода, согласовать очистку |
| Gate | SQLite, результат 24 часа, строка операции 48 часов | Просроченный ключ должен оставаться запрещённым после очистки строки |
| Процессы | Сохранённые ключ, хеш запроса и идентичность процесса | Сохранить дедупликацию после перезапуска |

storage.session переживает перезапуск service worker. Перезапуск браузера
требует отдельной проверки устойчивого состояния. До выбора механизма для этапа 6
нужно воспроизвести потерю session-хранилища и сбой fallback-записи. Формат файлов
агента и таблица Gate имеют собственные переходы, их миграции проверяются раздельно.

## Измерения

14 ноября 2026 года на исходном коммите Node-набор дал 294 проверки,
289 успешных, 5 пропущенных, 0 ошибок. Пропуски относятся к отдельным
реальным процессам и Chrome. Все четыре Go-пакета прошли без ошибок
с отключённым кэшем результатов. Новый корпус прошёл 8 из 8 проверок.
Это исходная точка до добавления корпуса.

Извлечение проверяется DOM-наборами, оформление, неполнота, неоднозначность
и схема отдельными примерами корпуса. Исполнение проверяется журналами агента
и Gate, доставка стендом жизненного цикла. Число studio.deliver для ошибок
разбора на этапе 1 должно стать нулём, включая чередующиеся повреждённые ответы.

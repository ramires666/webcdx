# AIX для Google AI Studio

Расширение Chrome соединяет чат Google AI Studio с локальным агентом на этом компьютере.
Агент читает и изменяет файлы, запускает команды и возвращает результаты в тот же чат.
Рабочий комплект использует прямое соединение по 127.0.0.1. Браузерные инструменты отключены.
Исходный код Gate и прежних интеграций сохранён для будущей работы.

## Готовый комплект

Проект находится в `W:\_python\webcdx`. Готовые файлы находятся в `bin/aix`.
`webcodex-agent.exe` версии `1.5.0-ai-studio-alpha.13` скомпилирован в локальном режиме.
`webcodex-ai-studio-bridge.zip` содержит расширение версии `0.5.9`.
Для установки готового комплекта самостоятельная сборка не нужна.

Распакуйте ZIP в постоянную папку. В `chrome://extensions` включите режим разработчика,
нажмите «Загрузить распакованное расширение» и выберите эту папку.
Если расширение загружено из папки исходников, обновите его на странице chrome://extensions.
Сохраните чат и перезагрузите вкладку AI Studio.

Остановите прежний агент и запустите `start-local-agent.cmd` из корня проекта двойным щелчком.
Он запускает один локальный агент из `bin/aix/webcodex-agent.exe`.
При стандартной установке OpenCode 2 через npm скрипт также находит `opencode.exe`
и базу активного подключения OpenCode Go. Свои пути можно задать переменными
окружения из инструкции по задачам.
Gate обновлять и перезапускать не требуется. Дополнительное расширение управления браузером не требуется.

Для выбора папки проекта можно запустить готовый EXE из PowerShell.

```powershell
$env:WEBCODEX_ALLOWED_ROOTS = 'W:\HARDDEV\smartgold'
& 'W:\_python\webcdx\bin\aix\webcodex-agent.exe' --local
```

`$env:` задаёт переменную окружения текущего окна и дочернего процесса.
`WEBCODEX_ALLOWED_ROOTS` задаёт разрешённые папки файловых инструментов. Вместо
`W:\HARDDEV\smartgold` подставьте свой путь. Несколько путей разделяются точкой с запятой.
Команды оболочки выполняются с правами пользователя, область файловых инструментов их не ограничивает.
`&` запускает EXE по следующему пути. Замените полный путь, если проект находится в другой папке.
`--local` обозначает локальный запуск. Эта сборка также работает без аргументов и игнорирует настройки подключения Gate.
Настройки и журнал агента в профиле пользователя сохраняются при переносе проекта.

В панели нажмите «Разрешить всё», затем «Запустить сеанс». Повторное нажатие кнопки
разрешений снимает все галочки. Кнопка «Отключить» завершает сеанс расширения.

## Сборка из исходников

Нужны установленный Go 1.25 или новее и PowerShell. Из корня проекта выполните
`./build.ps1`. Скрипт собирает локальный агент с тегом `aistudio` и упаковывает расширение
в `bin/aix`. Сам агент автоматически не запускается. `build.bat` запускает этот же сценарий.
`build.sh` собирает локальный агент для текущей системы, расширение на Windows упаковывается через `build.ps1`.

Историческая документация находится в `README.legacy.md`, `README.ru.legacy.md` и `docs`.
Прежние многокомпонентные сценарии сохранены как `build-legacy.bat` и `build-legacy.sh`.

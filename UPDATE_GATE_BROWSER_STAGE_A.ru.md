# Как обновить WebCodex до 1.4.0

Для поставки **1.4.0** обнови **Gate, агент и расширение**: добавились общие
инструкции работы с существующими вкладками и новые параметры инструментов.

**Да, EXE агента нужно заменить:** исправления чтения, ввода и загрузок находятся
в самом агенте. Одного обновления Gate недостаточно.

## 1. Gate на сервере

1. Подключись к серверу по SSH.
2. Вставь команды ниже. Если папка установки другая, замени `/opt/webcdx` на свою.

```bash
cd /opt/webcdx &&
git pull --ff-only origin main &&
docker compose up -d --build --no-deps gate
```

Команды получают код из Git, собирают Gate и запускают новый контейнер.
Если одна команда завершится ошибкой, следующие не выполнятся.
База, токены и настройки остаются прежними.

Что означает каждая часть:

- `cd /opt/webcdx` — перейти в папку установленного проекта; подставь свою папку.
- `&&` — выполнять следующую команду только при успехе предыдущей.
- `git pull` — получить и применить изменения из Git.
- `--ff-only` — обновить ветку только без создания merge-коммита; при расхождении остановиться.
- `origin` — имя удалённого репозитория; `main` — ветка с обновлениями.
- `docker compose up` — создать или обновить и запустить контейнер сервиса.
- `-d` — оставить контейнер работать в фоне.
- `--build` — сначала собрать образ из обновлённого кода.
- `--no-deps` — не запускать и не пересоздавать зависимые сервисы.
- `gate` — имя сервиса Gate в `docker-compose.yml`.

3. Через 30–60 секунд проверь:

```bash
docker compose ps gate
```

Должно быть **Up (healthy)**. Открой привычную страницу `/admin` и проверь агентов.
`docker compose ps gate` показывает состояние сервиса `gate`; `ps` — список контейнеров.
Если запуск не удался, покажи вывод:

```bash
docker compose logs --tail=50 gate
```

`logs` показывает журнал сервиса `gate`; `--tail=50` — только последние 50 строк.

Работай в прежней папке установки. Не используй `docker compose down -v`:
`down` останавливает и удаляет контейнеры проекта, а `-v` удаляет также Docker volumes,
включая данные базы. Резервная копия необязательна для запуска обновления;
она нужна для возврата к прежним данным при откате.

## 2. Агент на Windows

**Компилировать агент не нужно — он уже собран.** Готовый Windows EXE находится
в архиве `bin/webcodex-test-1.4.0.zip`, внутри папки
`test-1.4.0/webcodex-agent.exe`. Локальный путь к архиву:
`W:\_python\webcdx\bin\webcodex-test-1.4.0.zip`.
Go и запуск `build.bat` для установки этого комплекта не нужны.
Сам архив не хранится в Git: `git pull` получает исходники, а готовый EXE берётся
из этого архива. На сервере команда Docker из раздела 1 сама собирает **Gate**.

1. Распакуй `webcodex-test-1.4.0.zip`.
2. Останови старый агент: нажми **Ctrl+C** в его консоли.
3. Скопируй новый `webcodex-agent.exe` из распакованной папки `test-1.4.0`
   **на место старого EXE**, согласившись на замену.
4. Запусти свой прежний `start-agent-*.bat`. Звёздочка здесь означает твоё имя
   файла, например `start-agent-jinn.bat`; это не команда для вставки.

Сохрани прежние BAT-файлы и настройки: в них уже указаны адрес Gate и токен.
Перезапуск старого EXE без его замены не установит исправления.

Если EXE остался по прежнему пути и связь с браузером уже настроена, повторная
регистрация не нужна. Если перенёс EXE или настраиваешь связь впервые, открой
PowerShell в окончательной папке агента и выполни:

```powershell
.\webcodex-agent.exe --install-browser-host
```

`.\` означает текущую папку; `webcodex-agent.exe` — новый агент;
`--install-browser-host` регистрирует его путь для связи с Chrome/Edge под текущим
пользователем. Это команда настройки, после неё агент запускается прежним BAT.

## 3. Расширение и подключение

1. Замени **всю** установленную папку `browser-extension` папкой из комплекта.
2. Открой `chrome://extensions` или `edge://extensions` и нажми кнопку
   перезагрузки у **WebCodex Local Browser**. Проверь версию **1.4.0**.
3. Обнови список инструментов MCP в подключении WebCodex и начни новый чат.

Проверь, что агент подключился к Gate, а консоль показывает вкладку и результат
чтения. Подробная настройка: [BROWSER_GUIDE.ru.md](BROWSER_GUIDE.ru.md).

# Как обновить Gate

Для поставки **1.4.0** обнови **Gate, агент и расширение**: добавились общие
инструкции работы с существующими вкладками и новые параметры инструментов.

Если нужно обновить и сервер:

1. Подключись к серверу по SSH.
2. Вставь команды ниже. Если папка установки другая, замени `/opt/webcdx` на свою.

```bash
cd /opt/webcdx &&
git pull --ff-only origin main &&
docker compose up -d --build --no-deps gate
```

Команды получают код из Git, собирают Gate и запускают новый контейнер.
Если одна команда завершится ошибкой, следующие не выполнятся.
База, токены и настройки остаются прежними.

3. Через 30–60 секунд проверь:

```bash
docker compose ps gate
```

Должно быть **Up (healthy)**. Открой привычную страницу `/admin` и проверь агентов.
Если запуск не удался, покажи вывод:

```bash
docker compose logs --tail=50 gate
```

Работай в прежней папке установки. Не используй `docker compose down -v`:
эта команда удаляет данные. Резервная копия необязательна для запуска обновления;
она нужна для возврата к прежним данным при откате.

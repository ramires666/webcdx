Политика инструментов (Tool Policy)

Через запятую. Если список пуст — разрешены все инструменты (кроме запрещенных).
Через запятую. Запрещенные инструменты фильтруются в первую очередь.

Подключение агента (Windows PowerShell)

Запустите эти команды на рабочем компьютере, где установлен webcodex-agent.exe:
$env:WEBCODEX_GATE_URL = "{{.PublicURL}}"
$env:WEBCODEX_AGENT_TOKEN = "<ВАШ_AGENT_TOKEN>"
$env:WEBCODEX_ALLOWED_ROOTS = "C:\projects;D:\work"
$env:WEBCODEX_LOG_DIR = "$PSScriptRoot\logs"
.\webcodex-agent.exe

# Проверка тестовой поставки 1.4.0

Дата: 2026-10-25, Asia/Qyzylorda. План: [BROWSER_NEXT_STABILITY_PLAN.ru.md](BROWSER_NEXT_STABILITY_PLAN.ru.md).

## Что готово

- Обычная консоль показывает действие, вкладку/окно, URL, прочитанный фрагмент,
  результат, длительность и состояние загрузки. Секретные параметры URL скрыты;
  вводимые значения полей не выводятся.
- Очереди, deadline и epochs ограничивают зависания. Ограниченный writer сохраняет
  операции вне общего mutex. Повреждённый журнал не блокирует остальные инструменты,
  но запрещает новые изменения браузера до устранения ошибки.
- `reuse_only` с `exact_url`, профилем и окном выбирает существующую вкладку.
  Последующие действия проверяют `binding_revision` и фактическую цель.
- Повторный полный snapshot требует 4 IPC-запроса вместо 10, light — 3.
  Scoped read обходит выбранный контейнер. DOM records возвращают стабильные ID,
  cursor и revision. Прокрутка контейнера сообщает видимые и новые ID.
- Native-ввод поддерживает Unicode, undo и проверку результата. Тест перехвата
  фокуса не допускает записи в соседнее поле. Click/select сохраняют фокус окна
  по умолчанию; активация доступна явно.
- Кеш результатов ограничен 32 MiB. Диагностика отвечает без ожидания очереди
  вкладки; медленная DNS-проверка не блокирует чтение IPC.
- `save_download` проверяет байты, SHA-256, MIME и размеры изображения; повтор
  не перезаписывает идентичный файл. Исправлена обработка событий загрузки,
  пришедших в обратном порядке.
- Локальный capture store сохраняет файл вместе с точной подписью и метаданными,
  восстанавливает manifest/audit/checkpoint с диска после прерывания.

## Сборка и установка

Архив: `bin/webcodex-test-1.4.0.zip`; отдельная папка: `bin/test-1.4.0/`.
Бинарники собраны из чистого коммита `df2160219ff1` с Go 1.25.6,
`CGO_ENABLED=0`, `GOARCH=amd64`, `-trimpath`, `-ldflags="-s -w"`.
Версия исходников и `vcs.modified=false` проверены через build info.
Версия расширения — 1.4.0. Собранные файлы не включаются в Git.

Проверены запуск Windows-агента до ожидаемой ошибки отсутствующей конфигурации
и `/healthz` Windows Gate: HTTP 204 на отдельной временной базе и свободном порту.
Linux Gate проверен компиляцией. Контрольные суммы файлов и содержимое ZIP сверены.
Работающие процессы и база пользователя не заменялись.

Обновление Gate: [короткая инструкция](UPDATE_GATE_BROWSER_STAGE_A.ru.md).
Обнови также Windows-агент и полную папку расширения 1.4.0, перезапусти их
и обнови список инструментов MCP. Подробности: [руководство](BROWSER_GUIDE.ru.md).

## Что ещё не подтверждено

Реальная установка Jinn, авторизованный профиль и данные V-Shape не менялись.
`TestInstalledPersonalBrowserLive` пропущен: нужен отдельный запуск установленного
расширения и native host. Тесты адаптеров не заменяют проверку полного lifecycle
установки Chrome/Edge. Windows HWND, DPI, IME и системный Save As отдельно
не проверялись.

Полнота удалённой истории и оригинальность файлов не подтверждены.
`source_original_verified`, `collection_complete`, `history_end_verified`
и `coverage_complete` не становятся истинными только по размеру файла или DOM.
Автоматического `capture_channel` пока нет: готовы отдельные компоненты чтения,
прокрутки, штатной загрузки и возобновляемого локального сохранения.

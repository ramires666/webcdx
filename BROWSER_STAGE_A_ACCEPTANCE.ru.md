# Приёмка очередей и отмены браузерных операций

Дата: 2026-10-24, Asia/Qyzylorda. Поставка A и независимый пункт B1 из
[плана](BROWSER_NEXT_STABILITY_PLAN.ru.md). Расширение: **1.3.0**, command protocol 2.

## Изменения

- До отправки проверяется отмена контекста. IPC-команда содержит срок исполнения,
  ID подключения и версию доступа. Отмена с подтверждением проходит вне очереди.
- На сессию Go и подключение расширения приходится одна активная операция/команда
  и до восьми ожидающих. Переполнение возвращает browser_busy. Пауза, cancel,
  disconnect и смена доступа удаляют ожидающие действия; resume их не возобновляет.
- Проверка версии сессии закрывает гонку между выдачей permit и паузой. Устаревшие
  scope/control сообщения не перезаписывают новое состояние управления. Локальная
  пауза действует до завершения асинхронного сохранения настроек расширения.
- Новое подключение не ждёт зависшей очереди старого. Guard проверяется повторно
  после подготовки вкладки, до ввода/навигации. Очередь активного CDP-вызова не
  освобождается искусственно: следующая мутация не пересекается с ним.
- Phase и code/message/recovery согласованы. Отмена до возможного изменения даёт
  cancelled_before_dispatch/stop, потеря определённости после отправки —
  outcome_unknown/verify_outcome. Перезапущенная незавершённая операция имеет
  phase=unknown. Повтор request_key продолжает возвращать прежний исход.
- Native messaging проверяет UTF-8 байты JSON, включая кириллицу и emoji, до
  отправки. Обновлены схемы, guide и упаковка нового command_queue.js.

Отрицательные сценарии: отменённый context не отправляет байты; протокол 2
сохраняет deadline/connection/scope; старый протокол отклоняет mutation и разрешает
read; cancel_ack не закрывает профиль; старый access binding не отправляет команду;
отменённый и просроченный queued Input не исполняется; переполнение не добавляет
девятый waiter; pause/resume не оживляет старую мутацию; отмена во время tabs.get
не пропускает Input; новое соединение работает при зависшем старом read;
неправильные connection/scope и устаревший remote resume отклоняются; локальная
pause блокирует Input даже при задержке storage.set; UTF-8 бюджет проверен на границе.

Первый общий прогон обнаружил старый тестовый personal adapter без protocol 2.
Он обновлён до нового handshake и проверяет envelope; целевые и общий повторные
прогоны прошли. Временный Go-файл исследовательского overlay перенесён в
игнорируемый Go-каталог tmp/_design_review, чтобы не попадать в ./....
Журналы, архивы и бинарники проверок остаются в игнорируемом tmp/.

## Применение и оставшиеся работы

Обновить агент и полную папку расширения 1.3.0, перезагрузить расширение во всех
используемых профилях, обновить metadata MCP-инструментов для всех задействованных
агентов. Смешанные версии допускают чтение; mutation требует совместимого протокола.
Процедура установки описана в [guide](BROWSER_GUIDE.ru.md) и
[предыдущей приёмке](BROWSER_RELIABILITY_ACCEPTANCE.ru.md).

Рабочая установка и реальные пользовательские аккаунты не изменялись.
TestInstalledPersonalBrowserLive пропущен: требуется отдельная приёмка реального
расширения и native host. Node VM и personal IPC adapter не проверяют весь
lifecycle установленного расширения. Уже переданное Chrome действие отмена
не отзывает; при неизвестном исходе требуется проверка состояния сайта.

Дальнейшие B/C/D/E, включая быстрый snapshot, изоляцию повреждённого журнала,
политику фокуса и typed batches, остаются отдельными поставками. Эта приёмка
не обещает незаметность автоматизации и не подтверждает обновление рабочих компонентов.
